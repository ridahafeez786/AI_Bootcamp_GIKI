How to Run the Notebooks

Most notebooks were developed in Google Colab.

Open the required .ipynb file.
Click Open in Colab, or download and upload it to Google Colab.
Select the appropriate runtime:
CPU for small machine-learning exercises
GPU for deep-learning and LLM notebooks
Run the installation and import cells first.
Run the remaining cells in order.

Some notebooks may require additional datasets or API credentials. Relevant instructions are included inside those notebooks where applicable.
